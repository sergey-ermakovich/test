# Zeekr Probe

Тестовый APK для головного устройства Zeekr 7X. Проверяет две вещи:

1. ставится ли вообще стороннее приложение на ГУ;
2. какие данные машины доступны стороннему приложению через Android Automotive
   car-service (скорость, одометр, заряд батареи, запас хода и т.д.).

Ничего не меняет в машине: только читает и показывает.

## Где взять APK

Каждый push собирает APK в GitHub Actions и публикует его в **Releases** этого
репозитория. Ссылку на `.apk` можно открыть прямо из браузера ГУ или скачать
на флешку.

## Что показывает

* Верхняя зелёная панель обновляется раз в 0.7 с: скорость и одометр из
  car-service, батарея, запас хода, передача, температура за бортом, GPS
  (скорость, координаты, спутники), акселерометр.
* Ниже — полный отчёт: устройство и версия прошивки, выданные разрешения,
  все свойства car-service с текущими значениями или причиной отказа,
  системные библиотеки, пакеты производителя и объявляемые ими разрешения,
  системные сервисы, провайдеры локации, датчики, `getprop`.
* Кнопки: **Обновить**, **Разрешения** (повторный запрос), **Сохранить**
  (в Downloads и в папку приложения), **Поделиться**.

Главное, что нужно от отчёта: секции `ECARX ADAPTAPI` и `CAR SERVICE`.
ECARX AdaptAPI (`com.ecarx.xui.adaptapi.car.Car`) — это путь, которым данные
машины реально читаются на Zeekr без разрешений (так делают открытые проекты
[zeekr-shortcut-car](https://github.com/dts88/zeekr-shortcut-car) и
[zee-power-toys](https://github.com/maxim-saplin/zee-power-toys)).
Стандартный `android.car` на Zeekr обычно закрыт или отдаёт замороженные значения.
В секции `CAR SERVICE`: Если там
`SecurityException` — свойство существует, но закрыто; если
`IllegalArgumentException` — такого свойства у машины нет.
